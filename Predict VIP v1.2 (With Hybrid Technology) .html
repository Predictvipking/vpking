How to Use

Simulation Instructions:

Step Description
1Go to the "Simulation" tab.
2Set your desired "Initial Bet Amount" (e.g., 10). Click "Set Initial Bet / Reset Sim". This starts the simulation with a ₹10,000 fund.
3Enter the last 4 digits of the first period you want to simulate. Click "Predict".
4The tool shows the prediction and the "Current Bet" amount (starts with your initial bet).
5Observe the actual result (imagine it or use historical data if available).
6In the History table, click "Win" or "Loss" for that period.
7The Simulation Fund updates (Simplified: Win adds bet, Loss subtracts bet).
8The "Current Bet" for the *next* prediction updates automatically using Martingale (doubles on loss, resets to initial bet on win).
9The tool predicts the next period.
10Warning: If the Fund becomes too low for the next calculated bet, the simulation stops. Click "Set Initial Bet / Reset Sim" to start over.
11Repeat steps 5-10 to see how the strategy plays out in simulation. Use "Clear History Only" to clear results without resetting the fund/bet.

REMEMBER: This is a simplified simulation. Real game payouts differ. Martingale is extremely risky and can deplete funds quickly. Learn the concepts, don't rely on this for real money.
